Utwórz klasę Mysqldb która dziedziczy po klasie abstrakcyjnej database właściwości metody oraz metody abstrakcyjne.

Dołącz do klasy Mysqldb interfejs dołącz interfejs Sqlinterface do Mysqldb.

Abstrakcyjna klasa powinna zawierać odpowiednie właściwości do połączenia się z bazą danych za pomocą funkcji mysqli connect.

Abstrakcyjna klasa database ma zawierać odpowiednie metody do operowania na CRUD

1.Tworzenie bazy danych

2.Tworzenie tabeli

3.Odczytywanie danych z tabeli 

4.Aktualizacja tabeli

5.Usuwanie tabeli

Sql interfejs ma implementować metody takie jak findall(), find(), readOne(), readFirstTen


Wszystkie metody obiektu z klasy Mysqldb mają być sprawdzone i wywołane w kodzie.

!! Dodatkowe punkty będą uwzględnione za implementacje własnej metody testującej poprawnosć działania metod naszego obiektu
